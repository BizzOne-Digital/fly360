# FLYY 360 Frontend

Public website and admin panel for FLYY 360 – Raw & Reel.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

## Environment Variables

```
VITE_API_URL=http://localhost:5000/api
```

## Scripts

- `npm run dev` - Start development server (port 5173)
- `npm run build` - Production build
- `npm run preview` - Preview production build

## Admin Panel

Access at `/admin/login` after seeding the backend database.
